# Классы для стандартной библиотеки

В роли выделения классов для формирования стандартной библиотеки можно взять следующие классы:
- **Watcher** и **Subscriber** (сформированы на основе `observer`, который может быть спокойно переиспользован в других проектах для уменьшения связности между классами и для повышения гибкости в использовании)
- Родительские классы **General** и **Any**, от которых удобно наследовать классы и связывать их в общую систему
- Классы связанные с Компонентами (**Component, ComponentSet, ComponentQueue**), эти классы реализованы достаточно гибко для переиспользования в других проектах, где понадобится карта с отображением каких-то компонент (графических иконок)
